# ☕ Mr Black — نظام الكافتيريا

نظام كامل لكافيه **Mr Black**: منيو للزبائن عبر QR، ولوحة كاشير وإدارة، وشاشة مطبخ، ومساعد ذكاء اصطناعي للموظفين.
الواجهة عربية بالكامل (RTL)، وتعمل على الجوال والتابلت والكمبيوتر.

## 🧭 كيف يعمل النظام؟

```
الزبون يمسح QR ─► index.html ─► دالة place_order (تحسب السعر على السيرفر)
                                          │
                                          ▼
                              قاعدة بيانات Supabase (RLS)
                                          │  تحديث لحظي (Realtime)
                     ┌────────────────────┴────────────────────┐
                     ▼                                         ▼
               casher.html                               kitchen.html
          (تنبيه صوتي + مؤقت)                  جديد ← قيد التحضير ← جاهز
                     │
                     └─► المساعد الذكي ─► Cloudflare Worker ─► Workers AI
```

- **GitHub Pages**: يستضيف الصفحات (ملفات ثابتة فقط).
- **Supabase**: قاعدة البيانات، وتسجيل دخول الموظفين، والتحديث اللحظي، ودالة إدارة الموظفين.
- **Cloudflare Worker**: المساعد الذكي.

## 📖 دليل الاستخدام السريع

### المدير — أول مرة
1. افتح `casher.html` وسجّل الدخول.
2. **الإعدادات**: اضبط نسبة رسوم الخدمة والضريبة ومدة اعتبار الطلب متأخراً.
3. **المنيو**: عدّل الأسعار التجريبية أو احذفها، وأضف أصنافك. فعّل "تتبّع المخزون" للأصناف المعدودة (حلويات، ساندويشات…).
4. **الطاولات و QR**: اطبع رموز QR والصقها على الطاولات.
5. **الموظفون**: أضف حسابات الكاشير والمطبخ.

### الكاشير
- افتح `casher.html` واضغط **🔔 تفعيل الصوت** (المتصفح يتطلب ضغطة لتشغيل الأصوات).
- تظهر الطلبات الجديدة فوراً مع صوت. اللون الأحمر = متأخر.
- عند التسليم اضغط **تم التسليم**. زر 🖨 يطبع الإيصال.

### المطبخ
- افتح `kitchen.html` على شاشة/تابلت المطبخ واضغط **🔔 تفعيل الصوت**.
- **بدء التحضير** ← **جاهز ✓**.

### قفل الواي فاي (يمنع الطلبات الوهمية من خارج الكافيه)
1. من جهاز **متصل بواي فاي الكافيه** افتح `casher.html` ← تبويب **الشبكة**.
2. اضغط **استخدم شبكتي الحالية**، فعّل **تفعيل القفل**، ثم **حفظ**.
3. الآن من يفتح المنيو من خارج الشبكة (حتى لو صوّر رمز QR) يرى رسالة "اتصل بشبكة واي فاي الكافيه"، وقاعدة البيانات ترفض أي طلب منه.
- إذا تغيّر عنوان إنترنت الكافيه (بعد إعادة تشغيل الراوتر مثلاً) كرّر الخطوة 2.
- التحقق يتم على السيرفر بعنوان IP الذي تضعه Cloudflare (`cf-connecting-ip`)، وقد اختُبر أنه لا يمكن تزويره من المتصفح.

### الجرد
- تبويب **الجرد**: اختر اليوم / آخر 7 أيام / هذا الشهر أو فترة مخصّصة.
- يعرض رصيد البداية + التوريد − المبيع − التالف = رصيد النهاية، مع **تصدير CSV** (يفتح في Excel) و**طباعة**.
- كل تغيير في المخزون يُسجَّل؛ لا يمكن تعديل الكمية مباشرة إلا عبر توريد/تالف/جرد فعلي.

## 🔐 الأمان (ملخص)

- **RLS مفعّل على كل الجداول.** الزبون (anon) يقرأ فقط أعمدة محددة من المنيو والعروض الفعّالة.
- **الطلب عبر `place_order` فقط**: تحسب السعر والخصم والخدمة والضريبة من قاعدة البيانات، وتتحقق من التوفر والمخزون، وتمنع الإغراق (3 طلبات/دقيقة للطاولة).
- **قفل الواي فاي** (اختياري): عند تفعيله لا تُعرض بيانات المنيو ولا يُقبل طلب إلا من عناوين شبكة الكافيه.
- **XSS**: كل نص يُعرض يمر عبر دالة تنظيف (`html\`\`` في `js/common.js`)، مع Content-Security-Policy تمنع أي سكربت خارجي.
- **CSV**: حماية من حقن الصيغ في Excel.
- **المساعد**: CORS محصور بالموقع، تحقق من جلسة Supabase ومن أن المستخدم موظف فعّال، حدود للطول (سؤال ≤ 1000 حرف، ≤ 10 رسائل)، وحد 15 سؤالاً/دقيقة. يقرأ البيانات **بصلاحيات الموظف نفسه**.
- **لا أسرار في الكود**: المفتاح الوحيد في المشروع هو `sb_publishable_…` وهو عام بطبيعته.

## 🛠️ للمطوّر

**تعديل الواجهة**: عدّل الملفات ثم `git push`؛ GitHub Pages يحدّث الموقع خلال دقيقة أو دقيقتين.

**تجربة محلية** (تحتاج خادماً لأن الصفحات تستخدم ES modules):
```bash
npx serve .        # ثم افتح http://localhost:3000/index.html?table=1
```
> ملاحظة: إدارة الموظفين والمساعد الذكي يعملان فقط من دومين GitHub Pages (CORS).

**نشر المساعد**:
```bash
cd worker && wrangler deploy
```

**قاعدة البيانات**: الملفات في `supabase/migrations/` مطبّقة بالترتيب. اختبار الأمان: الصق `supabase/tests/security_test.sql` في SQL Editor واضغط Run (ينتهي بـ rollback ولا يترك بيانات).
